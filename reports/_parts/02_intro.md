## 2. Introduction

Text-to-SQL maps a natural-language question to an executable SQL query over a relational
database. The cross-database setting of Spider (Yu et al., 2018) is hard because every test
database is unseen: the model cannot memorise table or column names and must (i) *link*
question phrases to the right schema elements and (ii) respect the *structure* of the schema
(which column belongs to which table, how tables join through foreign keys).

RAT-SQL (Wang et al., 2020) addresses both with a single mechanism: question tokens, columns
and tables are encoded jointly by a transformer whose self-attention is *relation-aware* — every
pair of elements carries a relation type (schema-graph relation or schema-linking relation) whose
learned embedding biases attention keys and values. A grammar-based tree decoder then produces a
SQL abstract syntax tree.

This project re-implements the full pipeline from scratch and turns it into a controlled
experimental study of the research question:

> *How can explicit relational schema representation, schema linking, relation-aware attention,
> and grammar-constrained decoding improve natural-language-to-SQL generation and generalisation
> across unseen database schemas?*

## 3. Problem formulation

Input: question tokens `Q = (q_1..q_n)`; schema `S` with columns `C = (c_1..c_m)` (each with a
table, a type, primary-key and foreign-key flags; `c_1 = *`) and tables `T = (t_1..t_k)`;
optionally the database contents. Output: SQL `y` whose abstract syntax tree `a` is generated by
a sequence of actions `a_1..a_L` under a context-free grammar:

`p(a | Q, S) = Π_t p(a_t | a_<t, Q, S)` with `p(a_t | ·) = 0` for grammatically invalid actions.

Evaluation: Exact Match (component-wise set comparison, values ignored), Execution Accuracy
(result equality on the database), SQL validity (well-formed / executable).

## 4. Background

* **Seq2seq / sketch-based Text-to-SQL** (Seq2SQL, SQLNet, SyntaxSQLNet) struggle with unseen
  schemas because schema information enters only through column-name encodings.
* **Grammar-based decoding** (TRANX, Yin & Neubig 2018; IRNet, Guo et al. 2019) generates ASTs
  action by action and guarantees syntactic well-formedness.
* **Schema linking** (Guo et al. 2019; Bogin et al. 2019 with GNNs over the schema graph) makes
  question–schema alignment explicit.
* **Relation-aware self-attention** (Shaw et al., 2018) adds pairwise relation embeddings to
  transformer attention; RAT-SQL uses it to encode schema-graph and linking relations jointly,
  including *soft* relations between question tokens and schema elements.
